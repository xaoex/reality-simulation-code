# FOSS-XX Icons

This directory contains icons for the FOSS-XX store and applications.

## Icon Requirements

- Format: PNG (preferred), SVG, or ICO
- Size: 512x512 pixels (will be scaled as needed)
- Naming: `{appId}.png` for apps, `category-{id}.png` for categories

## Store Icons

- `foss-xx-icon.png` - Main FOSS-XX store icon
