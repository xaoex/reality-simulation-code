# FOSS-XX Application Packages

This directory contains application packages for the FOSS-XX store.

## Directory Structure

Packages should be named following the pattern:
- `{appId}-{version}-{platform}.{ext}`

For example:
- `dosbox-0.74-3-winxp.exe`
- `vice-3.7-linux-x86_64.tar.gz`
- `gimp-2.8.22-macos.dmg`

## Supported Package Formats

- `.zip` - Universal archive format
- `.tar.gz` - Unix/Linux archives
- `.exe` - Windows installers
- `.msi` - Windows MSI packages
- `.dmg` - macOS disk images
- `.deb` - Debian packages
- `.rpm` - Red Hat packages
- `.com` - DOS executables
- `.lha` - Amiga archives
- `.sit` - Classic Mac archives
